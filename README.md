# Data-Visualization-for-Big-Data-PBL-Team-12
# 온라인 쇼핑 탐색 행동과 구매 전환의 관계
### 신규 방문자와 재방문자의 비교 분석

온라인 쇼핑 세션의 탐색 행동과 구매 전환 간 관계를 분석하고, 신규 방문자와 재방문자의 차이를 시각화한 **빅데이터 시각화 PBL 프로젝트**입니다.

방문자 유형별 구매 전환율을 비교하고, 상품 페이지 탐색 폭과 페이지당 탐색 강도가 구매 여부와 어떤 관계를 갖는지 살펴보았습니다. 통계 모형을 통한 관계 분석과 머신러닝을 활용한 구매 전환 예측을 함께 수행했습니다.

## 1. 연구 질문

1. 신규 방문자와 재방문자의 관측 구매 전환율은 어떻게 다른가?
2. 상품 탐색 행동과 구매 전환의 관계가 방문자 유형에 따라 달라지는가?
3. 탐색 행동과 세션 맥락 변수를 활용하면 구매 여부를 어느 정도 예측할 수 있는가?

## 2. 데이터

**UCI Online Shoppers Purchasing Intention Dataset**

- [데이터 소개 및 다운로드](https://archive.ics.uci.edu/dataset/468/online+shoppers+purchasing+intention+dataset)
- [데이터 DOI](https://doi.org/10.24432/C5F88Q)

| 항목 | 내용 |
|---|---|
| 원본 규모 | 12,330개 세션, 설명변수 17개와 목표변수 1개 |
| 분석 단위 | 온라인 쇼핑 웹사이트의 방문 세션 |
| 목표변수 | `Revenue`: 세션 내 구매 발생 여부 |
| 비교 집단 | `New_Visitor`, `Returning_Visitor` |
| 주 분석 대상 | 신규·재방문 세션 12,245개 |
| 제외 대상 | `Other` 유형 85개 |
| 원자료 결측값 | 없음 |
| 원자료 완전 중복 행 | 125개 |

한 행은 한 번의 방문 세션을 나타냅니다. 따라서 재방문 유형만으로 해당 방문자의 과거 구매 경험이나 고객 충성도를 판단할 수 없습니다.

### 주요 변수

| 변수 | 의미 및 활용 |
|---|---|
| `VisitorType` | 신규·재방문 등 방문자 유형 |
| `ProductRelated` | 상품 관련 페이지 수, 상품 탐색 폭 |
| `ProductRelated_Duration` | 상품 관련 페이지의 총 체류시간 |
| `ProductIntensity` | 상품 페이지당 평균 체류시간으로 구성한 탐색 강도 |
| `HasProduct` | 상품 페이지 탐색 여부 |
| `Administrative`, `Informational` | 행정·정보 관련 페이지 수 |
| `Administrative_Duration`, `Informational_Duration` | 행정·정보 관련 페이지 체류시간 |
| `Month`, `Weekend`, `SpecialDay` | 방문 시점과 관련된 맥락 |
| `OperatingSystems`, `Browser`, `Region`, `TrafficType` | 접속 환경과 유입 맥락 |
| `Revenue` | 구매 발생 여부 |

`PageValues`, `BounceRates`, `ExitRates`는 산정 시점과 주 분석의 예측 목적을 고려해 주 예측 변수에서 제외했습니다. 해당 변수들을 추가한 결과는 별도의 진단 비교로 제시했습니다.

## 3. 분석 과정

### 데이터 점검 및 전처리

- 자료형, 결측값, 중복 행 및 변수 범위 점검
- 신규·재방문 세션 추출과 기타 유형 분리
- 상품 탐색 폭·페이지당 탐색 강도·상품 탐색 여부 구성
- 탐색 관련 수치 변수에 `log(1+x)` 변환 적용
- 동일한 설명변수 조합이 서로 다른 데이터 분할에 포함되지 않도록 그룹 구성
- 전처리와 예측 모델을 `Pipeline`으로 연결

### 탐색적 분석 및 시각화

- 방문자 유형별 구매 전환율과 신뢰구간 비교
- 전환율 차이에 대한 부트스트랩 분석
- 상품 탐색 폭과 탐색 강도를 함께 나타낸 탐색 지도 작성
- 방문자 유형별 페이지 수·체류시간 분포 비교

### 통계적 관계 분석

- 로지스틱 회귀를 이용한 탐색 행동과 구매 전환의 관계 분석
- 탐색 변수와 방문자 유형 간 상호작용 검정
- 스플라인 모형을 이용한 비선형 관계 분석
- 두 상호작용 검정에 Benjamini–Hochberg 다중검정 보정 적용
- 완전 중복 제거 및 상위 1% 제한에 따른 민감도 분석

### 구매 전환 예측

- `StratifiedGroupKFold`를 활용한 그룹 보존 분할
- 학습 표본 내 교차검증으로 후보 모델 비교
- 평균정밀도(AP)를 기준으로 모델 선택
- 검증 표본의 F1 점수로 분류 임곗값 선택
- 보류 시험 표본에서 전체·방문자 유형별 성능 평가
- 변수 묶음별 성능 비교와 순열 중요도 분석

비교 모델은 다음과 같습니다.

- Logistic Regression
- Random Forest
- HistGradientBoosting

## 4. 주요 결과

### 방문자 유형별 구매 전환율

학습·검증을 합친 개발 표본에서 신규 방문 세션의 관측 구매 전환율이 재방문 세션보다 높았습니다.

| 방문자 유형 | 세션 수 | 구매 세션 수 | 구매 전환율 |
|---|---:|---:|---:|
| 신규 방문자 | 1,356 | 338 | 24.93% |
| 재방문자 | 8,440 | 1,176 | 13.93% |

- 전환율 차이: **10.99%p**
- 차이의 95% 부트스트랩 구간: **8.56~13.48%p**
- 부트스트랩 반복 횟수: **2,000회**

전환율 차이는 반올림 전 수치로 계산했습니다.

### 탐색 행동과 방문자 유형의 상호작용

| 탐색 변수 | 보정 전 p값 | BH 보정 q값 | 해석 |
|---|---:|---:|---|
| 상품 탐색 폭 | 0.383 | 0.383 | 집단별 관계 차이에 대한 근거 불충분 |
| 페이지당 탐색 강도 | 0.039 | 0.077 | 다중검정 보정 후 유의하지 않음 |

신규·재방문 집단의 관측 전환율에는 차이가 있었지만, **탐색 행동과 구매 전환의 관계 자체가 방문자 유형에 따라 다르다는 근거는 다중검정 보정 후 충분하지 않았습니다.**

이는 두 집단의 관계가 동일하다는 것을 입증한 결과는 아닙니다.

### 구매 전환 예측 성능

학습 표본 내 교차검증 AP를 기준으로 **Random Forest**를 선택했습니다. 검증 표본에서 선택한 공통 분류 임곗값은 **0.20**입니다.

| 평가 집단 | 세션 수 | AP | ROC-AUC | Brier score | 정밀도 | 재현율 |
|---|---:|---:|---:|---:|---:|---:|
| 전체 | 2,449 | 0.347 | 0.765 | 0.116 | 0.308 | 0.579 |
| 신규 방문자 | 338 | 0.377 | 0.692 | 0.174 | 0.351 | 0.702 |
| 재방문자 | 2,111 | 0.335 | 0.770 | 0.107 | 0.295 | 0.544 |

AP는 평균정밀도를 의미하며, Brier score는 예측 확률의 오차를 나타내는 지표로 낮을수록 좋습니다. 집단별 표본 수와 구매 비율이 다르므로 성능 지표의 단순 비교에는 주의가 필요합니다.

### 탐색 행동 변수의 추가 정보

동일한 시험 표본에서 세션 맥락 변수만 사용한 경우와 탐색 행동 변수를 함께 사용한 경우를 비교했습니다.

| 변수 구성 | AP | ROC-AUC |
|---|---:|---:|
| 세션 맥락 변수만 사용 | 0.289 | 0.719 |
| 세션 맥락 + 탐색 행동 변수 | 0.347 | 0.765 |

이 자료와 평가 조건에서는 탐색 행동 변수를 포함했을 때 예측 성능이 더 높았습니다.

## 7. 실행 방법

### Google Colab

1. `Shopping_Behavior_All_in_One.ipynb`를 Google Colab에 업로드합니다.
2. **런타임 → 모두 실행**을 선택합니다.
3. 실행 완료 후 `shopping_results.zip`을 다운로드합니다.

원본 CSV가 노트북에 내장되어 있어 별도의 데이터 업로드나 경로 수정 없이 실행하도록 구성되어 있습니다. GPU는 필요하지 않습니다.

### 로컬 Python

Python 3.11 이상 환경에서 프로젝트 폴더로 이동한 뒤 실행합니다.

```bash
python -m pip install -r requirements.txt
python run_analysis.py
```

- 기본 설정은 `FAST=False`입니다.
- `FAST=True`는 빠른 실행 점검용이며, 최종 결과는 기본 설정으로 생성합니다.
- 노트북과 스크립트는 같은 출력 경로를 사용하므로 한 번에 하나만 실행합니다.
- 패키지 버전과 실행 환경에 따라 소수점 이하 결과나 실행시간이 달라질 수 있습니다.

## 9. 해석 범위와 한계

- 결과는 **세션 수준의 관측 연관성과 예측 성능**을 나타냅니다.
- 재방문은 재구매나 고객 충성도와 같은 개념이 아닙니다.
- 탐색시간이나 방문자 유형의 인과효과를 추정하지 않았습니다.
- 세션 전체 집계 변수를 사용하므로 실제 구매 전 실시간 예측 성능으로 해석할 수 없습니다.
- 무작위 그룹 분할 결과이며, 미래 기간이나 다른 쇼핑몰에서의 성능을 검증한 것은 아닙니다.
- 단일 공개 데이터셋과 사용자별 방문 이력 부재로 인해 일반화에 제한이 있습니다.
